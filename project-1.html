Urban Routes

UI and Regression Testing

Functional and UI testing of a web application for route planning and transportation services.

Project Overview

Urban Routes is an application that creates routes and calculates travel time and cost for different types of transportation.

The interface includes two address fields: "From" and "To". It also offers three route modes: "Optimal", "Flash", and "Personal", as well as icons for different transportation options, including personal car, walking, taxi, bicycle, scooter, and car sharing.

Once the user sets a route, the application displays the total travel time and fare based on a specific algorithm.

Testing Objectives

The application contained several defects. The objective of this project was to design and execute UI and functional test cases to identify defects and report them to the development team for resolution.

Testing was performed using Mozilla Firefox at a resolution of 1920×1080 and Google Chrome at a resolution of 800×600.

Methodology

Requirements Analysis

The functional and UI requirements were analyzed and broken down into testable conditions using checklists, equivalence partitioning, and boundary value analysis.

Test Case Design

31 functional and UI test cases were created to verify:

  • Correct input in the address fields
  • Proper button functionality
  • Correct fare calculation
  • Correct travel type based on the selected transportation option

Test Execution

The test cases were executed on the application's server.

Defect Reporting

The identified defects were reported in JIRA. Each bug report included a clear and concise title, reproduction steps, expected result, actual result, a screenshot, and the appropriate severity level.

Results

A total of 15 functional and UI defects were identified and documented in the application. The defects were reported to the development team for resolution according to their severity.

Tools Used

Requirements Documentation Checklists JIRA Urban Routes Server Figma Mozilla Firefox Google Chrome

Project Impact

This project helped identify functional and UI defects in the Urban Routes application and document them in JIRA for resolution.

Identifying and reporting these defects helped reduce potential negative impacts on the user experience, such as user frustration, negative reviews, and customer loss to competitors. Addressing these issues also helps protect the company's reputation and reduce potential financial losses.
