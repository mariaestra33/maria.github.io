Urban Grocers

API Testing

API testing of updated backend requirements for an application that creates grocery product kits and provides delivery services.

Project Overview

Urban Grocers is an application that manages product kits for users and provides delivery services.

Testing Objectives

The application had recently been updated with new services and requirements. The objective of this project is to analyze the updated backend requirements and verify that the API supported them correctly.

Methodology

Requirements Analysis

Two main requirements are analyzed: Users must be able to add existing products to a kit using the POST endpoint.

Each kit has a limit of 30 unique products. If more than 30 product IDs are added, the API should return an error.

The following API responses were also validated:

  • A 400 Bad Request response when non-existing product IDs are added.
  • A 404 Not Found response when products are added to a non-existing kit ID.
  • A 400 Bad Request response when the request body does not have the correct structure.

Test Case Design

A total of 58 positive and negative test cases were designed using equivalence partitioning and boundary value analysis.

The test cases covered:

  • Kit ID
  • Product ID
  • The structure of the "productList" array
  • The valid length of the "productList" array
  • The maximum limit of 30 unique products per kit

The required fields for the "Order and Go" service were also validated. The fields: "productsCount","productsWeight", and "deliveryTime" were tested according to the backend requirements.

Test Execution

An empty product kit was created in Postman using the following POST endpoint:

POST /api/v1/kits/{id}/products

The endpoint was used to execute the 58 test cases and validate the API responses against the expected results.

Bug Reporting

The identified errors were reported in JIRA. Each bug report included a clear and concise title, steps to reproduce, expected result, actual result, screenshot, and the appropriate severity level.

Results

A total of 7 functional bugs were identified and documented in JIRA. Then reported to the development team for resolution according to their severity.

Tools Used

API Documentation — apiDoc Backend Requirements JIRA Urban Grocers Server Postman

Project Impact

Validated API functionality against updated business requirements, helped ensure reliable product kit creation and delivery services while identifying potential issues before they could affect users.
