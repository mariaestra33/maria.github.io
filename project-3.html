Urban Grocers

Automation with Python

Automated repetitive tests using Python for an application that creates grocery kits and manages delivery services.

Project Overview

Urban Grocers is an application that creates product kits. A checklist was created to test the "Name" field in the product kit creation request

Testing Objectives

The objective of this project is to automate the test cases from the checklist using Python, upload the code to GitHub, and submit the repository for review.

Methodology

Connecting to GitHub

My personal GitHub account is connected to TripleTen, allowing the project repository to be submitted directly from the TripleTen platform.

Cloning the Repository

A project repository was created automatically and cloned to the local computer using the command line with SSH.

Working with the Project Locally

The project folder is opened in PyCharm. The Urban Grocers server is started to obtain the server URL, which is stored in “configuration.py” along with the API request endpoints.

Creating Test Requests

The API documentation is used to locate the endpoint for creating a new user and obtaining an authentication token. The token is then used to create a product kit for the user.

Creating a User and Product Kit

9 positive and negative test request bodies are created to automate different test cases for the "Name" field and verify its functionality according to the requirements. The POST request bodies are stored in “data.py”.

README.md and .gitignore

The “README.md” file contains information about the project, including its description and the tools used. The “.gitignore” file was configured to exclude files that should not be uploaded to GitHub.

Results

A total of 9 automated tests were executed. 6 tests passed and 3 tests failed.

Project Impact

This project automated 9 repetitive test cases for the "Name" field when creating product kits. The automation helped verify the functionality of the field, save testing time, optimize testing resources, identify and resolve functional issues that could potentially affect the user experience
